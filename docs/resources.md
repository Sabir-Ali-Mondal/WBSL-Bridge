# SignSetu — Sign Language Reference Resources

## 1. WBSL Dictionary — Wikisigns

**Language:** West Bengal Sign Language (WBSL)
**Type:** Word/sign dictionary
**Use:** WBSL vocabulary, individual signs, regional signs.

[http://www.wikisigns.org/list/bn/wbsl](http://www.wikisigns.org/list/bn/wbsl)

The dictionary contains entries such as আম, জল, মা, বাবা, মাছ, ভাত, পরিবার, বাস, রিকশা, রেলগাড়ি, colours, days, numbers, etc. ([wikisigns.org][1])
